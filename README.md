# AI Document Assistant

This is the first milestone of a beginner-friendly AI project.

## What we are building
We are creating a small backend that can start and respond to HTTP requests. Later, we will add document upload, AI questions, and document search.

## Milestone 1 goals
- Understand the project folder structure
- Learn basic Python syntax
- Learn how FastAPI creates web APIs
- Run a simple API locally

## Project structure
- backend/app/main.py : the main FastAPI application
- backend/requirements.txt : Python packages needed for this project
- .gitignore : files we do not want to commit
